# Memory Quest

Juego de memoria para móvil: el jugador debe emparejar cartas idénticas en el menor tiempo posible. A medida que se avanza de nivel, la dificultad aumenta y se pone a prueba la agilidad mental, la concentración y la memoria visual del jugador.

Hecho con Expo y React Native por Alfonso Jiménez, Sebastián Soto y Gregorio Carvajal (Fintu Technologies).

## Características

- **Temporizador:** cada partida cuenta con un tiempo límite.
- **Vidas:** el jugador dispone de un número limitado de intentos.
- **Niveles:** la dificultad incrementa progresivamente (más cartas por nivel).
- **Interfaz pixel art:** estética retro con música y efectos de sonido.
- **Sistema de puntuación:** los puntos se obtienen según el tiempo y la precisión del jugador, con estadísticas persistentes en el inicio.

## Ejecutar

```bash
npm install
npx expo start
```

Las compilaciones de producción se hacen con EAS (`eas.json`).
